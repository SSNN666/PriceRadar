## 2. 京东联盟（M0 生死线，最优先）

**入口：https://union.jd.com —— 只走联盟通道，不要走宙斯 JOS（那是商家接口，需企业资质）。**

1. 用京东账号登录 → 开通京东联盟 → 选 **"个人账户"**
2. 实名认证：身份证 + 人脸识别（与京东账号实名保持一致）
3. 左侧菜单 **推广管理 → 导购媒体管理 → 创建导购媒体**
   - 类型选"聊天工具/社交媒体"，名称填 `PriceRadar`（只用于区分，无硬性要求）
4. 对该媒体点 **推广位管理 → 创建推广位**，创建后记录：
   - **PID**（格式如 `203xxxxxxxx_xxxxxxx_3xxxxxxxxx`，所有推广链接归因都靠它）
   - 部分场景还会给 **社交媒体应用 key / secret**，一并记录
5. 联盟后台 → **API → 创建应用**，申请 **商品查询类接口** 权限（审核 1-3 工作日，这是生死线）
6. 审核通过后记录 **appKey / secretKey**

**易错点**
- **appKey/secretKey 来源**：导购媒体页给的"社交媒体应用 key/secret"≠ API 凭证。调 `jd.union.open.*` 接口用的 appKey/secretKey 必须在联盟后台 **工具 → API → 创建应用** 单独申请（就是上面的第 5 步），别拿社媒 key 填 .env
- **IP 白名单**：API 授权若要求配 IP 白名单，务必填，漏配调用直接 403。开发期家用宽带出口 IP 是动态的——一旦 403，先查 IP 是否漂移，再怀疑权限问题
- 命名规范：推广位名称用 `PriceRadar_web_2026Q4` 这类可读格式，否则报表没法看
- 限额：QPS 5-10、日调用约 5000 —— 代码层必须做 Redis 缓存 + 限流，这是后端叙事的一部分
- 微信内**不要**直接贴联盟原始链接（有阶梯处罚风险），一律走转链后的小程序跳转
- **载体兜底**：若"聊天工具/社交媒体"载体申请商品查询接口被拒，等 Web 上线后补建"网站"载体再申请——因此域名备案要尽早并行启动，别让"等 Web 上线"变成两周阻塞
- 后续若要提现佣金，绑定的银行卡实名需与账号一致（本项目佣金只归开发者，不涉及用户分佣）

## 3. 拼多多（两个平台，一个手机号）

### 3.1 拼多多开放平台（拿 client_id / secret）

1. **https://open.pinduoduo.com** 注册（手机号记住，后面多多进宝用同一个）
2. **立即入驻** → 开发者角色选 **"多多进宝推手"**（个人开发者只有这一个角色可选）
3. 组织资质选 **个人开发者** → 上传身份证人像面 + 国徽面 → 邮箱 + 手机验证 → 提交审核
4. 审核通过后：**控制台 → 应用列表 → 创建应用** → 类型选 **"多多客联盟"**
   - 应用图标 260×260；回调地址暂时填自己的域名即可（后期可改）
   - MRD/PRD 文档字段：可上传本项目 PRD 转格式顶替，不强制内容
5. 审核通过后进 **应用详情**，记录 **client_id + client_secret**

### 3.2 多多进宝（绑定 + 备案 + 拿 PID）

1. **https://jinbao.pinduoduo.com** 用**同一手机号**登录（验证码即可自动注册）
2. 顶部 **开发者中心** → 填入上面的 client_id 完成绑定
   ⚠️ **绑定一次后不可修改**，填之前核对三遍
3. **推广管理 → 推广者备案 → 新增媒体备案**
   - 选"他方平台 / 社交平台"，所属平台"微信"，类型"个人账号" → 提交，等审核
4. 备案通过后：**推广位管理 → 新增推广位** → 记录 **PID**
5. PID **授权备案**：在后台/接口生成授权链接，用拼多多 App 扫码确认（谁拿佣金谁授权，一个推手只需一次）

**易错点**
- 不绑定 client_id 直接调接口会报"非多多客"错误
- 订单类接口对个人关闭 —— 本项目不需要，无影响
- 两个平台用不同手机号注册 = 绑定环节直接卡死，务必同号

## 4. 博查 AI（10 分钟搞定，唯一要花钱的）

1. **https://open.bochaai.com** 注册（手机号/邮箱）
2. **https://open.bochaai.com/api-keys** 创建 API Key（`sk-` 开头），妥善保存
3. 充值页预付费（**预充值模式，不充不能用**）：最低约 ¥36 档；Web Search ¥0.036/次；新用户可能有 1000 次免费额度，以平台实际显示为准
4. 端点：`https://api.bochaai.com/v1/web-search`，Header 带 `Authorization: Bearer sk-xxx`

用途：Agent 的联网检索层（价格情报补充、商品资讯、评测信息），也是"检索增强决策"叙事里除联盟 API 外的第二数据源。

## 6. 拿到钥匙之后：填入 .env 并验证

把 7 个值填进项目根目录 `.env`（**加入 .gitignore，绝不提交**）：

```
JD_UNION_APP_KEY=
JD_UNION_SECRET_KEY=
JD_UNION_PID=
PDD_CLIENT_ID=
PDD_CLIENT_SECRET=
PDD_PID=
BOCHA_API_KEY=
```

三条最小验证（拿到 key 当天就跑，任何一条不通立即反馈）：

```bash
# 1. 京东商品查询（换成你的 appKey，走联盟 API 网关）
curl "https://api.jd.com/routerjson?method=jd.union.open.goods.query&app_key=$JD_UNION_APP_KEY&..."

# 2. 拼多多商品搜索
curl -X POST https://gw-api.pinduoduo.com/api/router \
  -d "type=pdd.ddk.goods.search&client_id=$PDD_CLIENT_ID&keyword=数据线&with_coupon=true"

# 3. 博查 Web Search
curl -X POST https://api.bochaai.com/v1/web-search \
  -H "Authorization: Bearer $BOCHA_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"query":"京东 优惠券 规则","count":5}'
```

验证结果记录到 `docs/api-verification.md`：每个接口实际返回字段、限流表现、可用字段与 PRD 假设的差异（这份数据直接影响到手价引擎的口径）。

| 时间 | 动作 |
