# M0 账号注册指引 · 三把钥匙

> 目标：拿到「京东联盟 / 拼多多开放平台（多多进宝）/ 博查搜索」的 API 凭证，接入真实数据（PRD §7 M0）。
> 用法：逐项打勾；所有凭证填入项目根目录 `.env`（模板见 [.env.example](../.env.example)，`.env` 已被 gitignore，不会进仓库）。

## 0. 一次性准备

- [ ] 身份证（实名认证）
- [ ] 本人银行卡（京东联盟需要绑定，用于结算/提现）
- [ ] 常用手机号 + 邮箱
- 预计：每家填写 15-30 分钟；审核普遍 1-3 个工作日（博查即时可用）

## 1. 京东联盟（M0 关键路径，最先提交）

**解锁**：京东商品详情 / 公开券 / 好评率 / 评论数 / 30 天销量 / 自营标识（PRD §5.1、§5.8 L1）

- [ ] **注册**：浏览器打开 https://union.jd.com → 用京东账号登录（没有就先注册）
- [ ] **实名认证**：右上角昵称 →「账号管理」→ 开通个人账户 → 身份证实名 + 绑定本人银行卡/京东钱包 → 提交（审核 1-3 个工作日）
  - 认证完成后复制左上角 **联盟 ID** 保存
- [ ] **创建推广载体**：「我的推广」→「推广管理」→「推广位管理」
  - 暂无网站的选「**新增导购媒体**」（推广渠道填微信），审核通过后点【查看】拿到 **媒体 ID / appkey / secretkey**
  - ⚠️ 导购媒体申请简单，但部分 API 权限有限制；若后续商品查询接口权限不足，等 Web 上线后补建「网站」载体
- [ ] **创建推广位**：「推广位管理」→「创建推广位+」→ 选择刚创建的载体 → 命名（如 `price-radar-test`）→ 确认，得到 **PID**
- [ ] **申请 API 权限**：联盟后台的「开放平台 / API 管理」入口 → 创建应用 → 申请「商品查询 / 关键词搜索」接口权限；用途如实填写（个人比价工具，学习用途）
  - 注意：走**京东联盟**通道，不要走宙斯（JOS）商家接口（那要企业资质）
- [ ] **配置 IP 白名单**（若控制台要求；漏配调用会 403）
- [ ] **邮件申请券接口**：发邮件到 `cps@jd.com`，说明用途，申请「优惠券相关接口」权限

> 📌 **实测记录（2026-10-05）**：签名算法（secret + 排序参数拼接 + secret → MD5 大写）可用；`timestamp` 必须用**字符串格式**（`yyyy-MM-dd HH:mm:ss`），毫秒/秒时间戳会报「时间戳参数不正确」；**未完成实名认证时接口返回 `code=431 未完成实名`**——需先到 union.jd.com/user 或京粉 App（我-账户信息）完成实名 + 绑卡。
> 📌 **接口可用性实测**：应用名 PriceRadar（AppKey `02a408b8...`，应用 ID 4108628055 = PID 中段，三者同一实体）。✅ `goods.jingfen.query` 正常（**无需 token**，自带好评率/评论数/30 天销量）；✅ `category.goods.get`、`bigfield.query`、`rank.query` 权限通过；❌ `goods.query` 未开通（403，疑为高级接口需邮件申请）；❌ `promotiongoodsinfo.query` 显示"已开通"但实际：无 token → 403，带 token → `code 67 网关依赖服务异常`（多 skuId、多参数格式稳定复现，疑似平台侧问题，**应提交工单**）。⚠️ 96 位"授权Key"是**工具商（第三方工具）模型凭证，不能当 access_token 用于自建应用调用**（报 code 19）。

**完成后应持有**：联盟 ID、媒体 ID、appkey、secretkey、PID

## 2. 拼多多开放平台 + 多多进宝

**解锁**：拼多多商品 / 公开券 / 销量（`sales_tip`）（PRD §5.1）

- [ ] **注册**：https://open.pinduoduo.com → 手机号注册 → 开发者类型选「我是第三方开发者」→ 身份类型「**个人开发者**」→ 填身份信息 → 提交审核（当天 ~ 3 个工作日）
- [ ] **创建应用**：审核通过后 → 控制台「创建应用」→ 应用类型选「**多多客联盟**」（多多进宝）→ 填应用名称/说明/图标/文档（可下载官方 PRD 模板原样导出 PDF 上传）/回调网址 → 提交（一般自动通过）→ 记录 **client_id / client_secret**
- [ ] **绑定多多进宝**：登录 https://jinbao.pinduoduo.com →「开发者中心 / API 权限」→ 绑定上一步的 client_id
- [ ] **推广者备案**：无网站选「他方平台 / 社交平台」→ 推广平台「微信」→ 类型「个人账号」→ 提交
- [ ] **创建推广位**：「推广位管理」→ 创建 → 得到 **PID**

**完成后应持有**：client_id、client_secret、PID

> ⚠️ 订单类接口对个人关闭（本项目不需要）；转链若报 `sub_code 60001` = 推广位未备案完成，等备案通过即可
> 📌 **实测记录（2026-10-05）**：搜索接口 `pdd.ddk.goods.search` 要求 **PID 授权备案**，未备案时报 `50001 / sub_code 60001`。备案方法：调 `pdd.ddk.goods.promotion.url.generate`（参数 `generate_authority_url=true`）生成授权链接 → 用拼多多账号访问并登录 → 完成备案；状态用 `pdd.ddk.member.authority.query` 查询（`bind: 1` = 已备案）。`pdd.ddk.goods.recommend.get`（推荐商品）无需备案即可调用。

## 3. 博查搜索 API（10 分钟，即时可用）

**解锁**：L2 风险检索管线（PRD §5.8）

- [ ] **注册**：https://open.bochaai.com → 手机号/邮箱注册
- [ ] **创建密钥**：控制台 →「API 密钥管理」→ 创建 API 密钥（选免费套餐）→ 复制保存
- [ ] **填 `.env` 后验证连通**：

```bash
.venv/Scripts/python scripts/check_bocha.py "索尼 WH-1000XM6 避雷"
```

**额度与价格**：新用户免费 **1000 次**（≈ 130-160 次商品级风险扫描，足够验证阶段）；之后按量约 ¥0.036-0.06/次
