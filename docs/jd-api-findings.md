## 2. 关键判断：网关鉴权完全正常

能拿到**业务层响应**（内层 code 403 / 62 / 67）说明以下环节全部通过，无需再排查：

- appKey / appSecret 正确
- 签名算法正确（md5：`secret + 排序k1v1k2v2... + secret` → MD5 → 大写）
- timestamp 格式正确（字符串 `YYYY-MM-DD HH:MM:SS`；毫秒/秒时间戳会被拒）
- **IP 白名单无问题**（若 IP 未放行，连业务响应都拿不到）

唯一被拒的是**单个接口的调用授权**——后台显示"已开通"但调用返回 403，属于权限状态与后台展示不一致。

需要向联盟核实时，带上这些 requestId：
- `promotiongoodsinfo.query`：`o_06550ef0_muv99vsh_81171306`
- `position.query`：`o_0b8e8252_muv9aqrk_81273706`

## 9. 京粉精选频道地图（eliteId）实测（2026-10-07）

**背景**：京东侧**没有关键词搜索**（`goods.query` 403 高级接口，个人不可申请），现有实现 `search_jd_channel(elite_id)` 只能拉固定频道池——**这是"搜京东搜不到东西"的根因**：搜"保温杯"时默认拉的是 `eliteId=24`（数码）的池子，保温杯根本不在里面。

**但实测发现两条出路**：

### 9.1 池子可以翻页拉大

`page_index` 翻页**真实有效**，无重复：`eliteId=24` 连续 5 页 × 50 = **250 条全部新增**。单频道可稳定拉取 300~500 条。

### 9.2 频道是分品类的 → 可做品类路由

| eliteId | 品类（据样本标题判断） | eliteId | 品类 |
|---|---|---|---|
| 1 | 食品（坚果/板栗/纸品） | 26 | 母婴（纸尿裤/玩具） |
| 2 | 综合（母婴/食品/日用） | 27 | **家居厨具**（苏泊尔/妙洁/欧普） |
| 3 | 家居家清（花洒/茶） | 28 | **美妆护肤**（娇韵诗/玉泽/欧莱雅） |
| 4 / 10 | 食品日用（**两者内容完全相同，为同一池别名**） | 29 | 医药（妈咪爱/排卵试纸） |
| 8 | 生鲜/家电（京鲜生/小熊） | 30 | 图书（寻宝记系列） |
| 9 | 美妆/食品/百货 | 31 | 母婴/图书/美妆 |
| 15 | 厨具/家居（爱仕达/荣事达） | 32 | **含服饰**（雪中飞秋冬男装）+ 医药/食品 |

**不可用频道**（报"资源位未生效或已失效"）：6、7、11、12、13、14、16、17、18、19、20、21、35、36

### 9.3 关键词覆盖率实测（品类路由后）

| 频道 | 池子 | 关键词命中 |
|---|---|---|
| 27 家居厨具 | 386 条 | 含"保温杯" **16 条** |
| 24 数码 | 400 条 | 含"耳机" **15 条** |
| 28 美妆 | 200 条 | 含"面膜" **5 条** |

→ **"品类路由 + 拉大池 + 标题关键词过滤"路线可行**，每个品类可得到十几条真实京东报价，足够做跨平台比价。

### 9.4 诚实的边界

- 京东侧**只覆盖平台当前推广中的商品**，不是全量库——用户搜一个京东没在推的商品，依然 0 结果
- 频道内容是**天级轮换**的（推广位变化），故覆盖率不稳定、不可复现
- 因此京东侧的角色应定位为「**可能存在的对比项**」，而非"双向搜索"；UI 与文案须如实说明，不能承诺"全平台比价"

### 9.5 覆盖率验证结论（2026-10-07，决定"是否放弃京东链路"）

**方法**：不做智能路由，直接拉全部 20 个可用频道的池子（8 页 × 50 = 最多 400 条/频道），按关键词过滤——得到的是**覆盖率天花板**。

**池子规模：6319 条商品。**

| 指标 | 结果 |
|---|---|
| 有结果 | **24/25 = 96%** |
| ≥3 条（够比价） | **22/25 = 88%** |
| 平均命中 | **23.2 条/查询** |

**放宽匹配后进一步提升**（精确子串 → 关键词切分 OR 匹配）：

| 查询 | 精确 | 放宽 |
|---|---|---|
| 降噪耳机 | 0 | **43** |
| 坚果零食 | 2 | **317** |
| 锅具 | 2 | 2（仍不足） |

> 关键：**"降噪耳机"0 条但"蓝牙耳机"23 条**——不达标的是**检索策略**（查询词过具体），不是频道覆盖。放宽匹配即可补上。

**每条结果都带好评率 + 评论数**（如 `★94.0／5000条`）——正是拼多多侧拿不到、Wilson 质量评估所依赖的字段。

### 9.6 结论：京东链路保留

**决策依据**：测算命中率 88~96% 远高于"放弃"阈值（<20%）。

**实施方向**：品类路由（查询 → 相关频道）+ 翻页拉池 + 关键词过滤（精确优先，不足时放宽）。
> ⚠️ 若放弃京东，则 §6 质量评估在拼多多侧上限恒为「一般」（平台仅两档评分），等于自废一半——这也是保留京东的主要理由之一。

### 9.7 ⚠️ 跨平台命中率的真实数字（2026-10-07，修复后实测）

**问题**：§9.5 测的是"京东能不能搜到商品"，但那不等于"能不能形成跨平台比价"。
搜到"保温杯"和搜到你想要的那个**苏泊尔**保温杯，是两回事。

**实测**（18 个品牌型查询，合并两轮）：

| 指标 | 结果 |
|---|---|
| 京东**有结果** | ~90% |
| 京东**有可比同款**（`cross_platform_hit`） | **2/18 ≈ 11%** |

命中案例：

```
蓝月亮洗衣液   京东 ￥9.89（蓝月亮深层洁净 500g瓶装）
             拼多多 ￥19.69（蓝月亮 500g*4袋补充装）   → 京东便宜一半
```

**未命中的原因不是匹配太严，是池子里没有**：苏泊尔保温杯、美的电饭煲、海飞丝等在
京东池 6319 条中**品牌命中 0 条**（8 页实测）。京粉频道池是"平台当前在推的商品"，
**不是京东全量库**。

### 9.8 结论：京东保留，但必须如实标注覆盖率

- ✅ **保留**：链路已修好、维护成本低（缓存每天刷一次 + 静态路由表）；命中时价值高（上例便宜一半）
- ⚠️ **不可承诺"全平台比价"**：只有约 10% 的查询能给出跨平台同款对比
- 💡 **产品定位应是**：拼多多侧为主（100% 可用），京东侧为**增值**——"当京东也有同款时告诉你"
- 💡 **另一条被低估的价值**：京东是**唯一能提供好评率+评论数**的平台，即 Wilson 质量评估唯一能给出「可信」档的来源；但受同样覆盖率限制
